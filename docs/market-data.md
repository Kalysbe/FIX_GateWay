# Текущие торги из БД QUIK

Источник — таблица `public."Params"` в БД экспорта QUIK, в том же подключении
`QUIK_EXPORT_DATABASE_URL`, что и `Orders`, только для чтения. Для локальной
разработки это `192.168.0.89:5432/quik_export2`, на проде — PostgreSQL QUIK
на `172.23.10.84:5432` (DSN хранится в секрете `quik-export-database-url`).
Роли Gateway нужен `SELECT` на `public."Orders"` и `public."Params"`.

По решению пользователя от 26.10.2026 строки передаются как результат
`row_to_json(p)`: все столбцы с исходными именами и значениями, включая
неизвестные Gateway поля и `null`. Числа остаются JSON-числами с исходной
точностью, строки — без обрезки и перевода. Gateway не добавляет поля,
не переименовывает их и не рассчитывает цены, статусы или признак «live».
Рыночные данные общие: строки не фильтруются по фирме токена.

Строка определяется парой `ClassCode` + `SecCode`.

| Метод | Ответ |
|---|---|
| `GET /api/v1/market-data` (брокер, `orders:read`) | JSON-массив строк Params |
| `GET /api/v1/market-data/{board}/{symbol}` | Одна строка по `ClassCode`/`SecCode` или 404 |
| `GET /api/v1/admin/market-data`, `GET /api/v1/admin/market-data/{board}/{symbol}` | То же для админки |
| gRPC/SSE `marketdata.tick` | Одна изменённая строка на событие |

`board` и `symbol` фильтруют `ClassCode` и `SecCode` (с обрезкой пробелов
`char(n)`). Порядок — `ClassCode`, `SecCode`. `limit` — 1–5000, по умолчанию
1000; `offset` — 0–10000000; продолжение — в заголовках `X-Has-More` и
`X-Next-Offset`.

Лента опрашивает всю таблицу раз в секунду и публикует изменившиеся строки.
В native gRPC исходный JSON строки находится в `Event.data_json`,
`Event.data` пуст; исчезновение строки — `Event.removed=true`. Browser SSE
передаёт строку в `data`, `removed` — рядом с `type`. Снимка при подписке нет:
начальный набор загружается через REST, затем применяются изменения по ключу
`ClassCode` + `SecCode`. Первый успешный опрос после старта — базовая выборка
и не рассылается.

Ошибка чтения даёт 503 без подстановки FIX-котировок. Фоновая ошибка не
считается пустой таблицей и не порождает удалений.

FIX-подписка Market Data (`35=V/W/X`) продолжает работать на сервере и
сохраняет снимки в `fix_md_snapshots`, но наружу через эти методы не
отдаётся. Стакан `GET /api/v1/orderbook` по-прежнему строится из FIX:
глубины рынка в Params нет. Котировки `Quotes(symbol)` на странице
«Котировки» не менялись.

Проверки охватывают идентичность JSON, точность длинных чисел, `null`,
`char(n)`-ключи, фильтры, пагинацию, 404/503 и рассылку всем подписчикам.
Интеграционные тесты используют те же `QUIK_ORDERS_*TEST_DATABASE_URL`, что
и тесты `Orders`; локальный стенд создаёт таблицу `Params` с двумя строками
(`deploy/local-quik-export.sql`).
