2.Формат запросов и ответов

  • Параметры и поля, обязательные для заполнения, отмечены символом «*».
  • Поля, входящие во вложенный объект или в элемент массива, отмечены символом «→».

2.1Подключение

URL шлюза, API-токен и параметры VPN-туннеля выдаёт представитель КФБ по запросу на it@kse.kg. Шлюз доступен только через VPN-туннель.

НаименованиеКомментарий
ТранспортHTTPS через VPN-туннель
Базовый URLhttps://<адрес-шлюза>/api/v1
СпецификацияOpenAPI 3.0, Swagger UI: /broker-swagger

2.2Авторизация

Bearer-токен в заголовке Authorization. Токен определяет брокера и FirmId QUIK. Фильтр по фирме применяется на стороне шлюза и параметрами запроса не расширяется.

2.3Формат ответа

application/json; charset=utf-8. Тело запроса разбирается строго: неизвестное поле — 400. Все методы, включая /health, отвечают в едином конверте:

НаименованиеТипКомментарий
success*логический«true» только для HTTP 200 и 201. Ответ 202 (QUIK ещё не ответил) приходит со значением «false»
code*строка«OK» или код ошибки, см. п. 8.1
message*строкаПричина ошибки. При успехе — null
error_code*числоЧисловой код причины от QUIK при отказе в заявке или снятии, см. п. 8.2. В остальных случаях — null
data*объект, массивРезультат: объект, массив строк QUIK или null. При ошибке, как правило, null. Заявка в data возвращается, если ответ касается её состояния в QUIK (раздел 5)
has_moreлогическийТолько у списков. «true», если есть следующая страница
next_offsetчислоТолько у списков. Значение offset для следующего запроса

Ветвление — по code; message — человекочитаемый текст QUIK или шлюза, его формулировка не стабильна.

2.4Постраничная выдача

Offset-пагинация (limit, offset) без снимка: при изменении таблицы QUIK между запросами возможны пропуски и повторы строк. has_more и next_offset дублируются в заголовках X-Has-More и X-Next-Offset.

2.5Данные QUIK, числа и торговый день

  • Строки QUIK (Firms, Trdaccs, Securities, Params, Orders, Trades, MoneyLimits, DepoLimits) передаются как row_to_json: без переименования, пересчёта и служебных полей. Состав колонок определяет QUIK; клиент должен допускать новые поля.
  • Строки Securities, Params, Orders и Trades, а также котировки и стакан ограничены классами, выбранными биржей (п. 9.1); без выбора — все классы. Позиции классами не ограничены.
  • Числа — JSON number без округления. OrderNum достигает 19 знаков и выходит за точный диапазон IEEE 754 double: нужен парсер с decimal или BigInt.
  • Торговый день — дата по UTC+6 (Asia/Bishkek); смена в 18:00 UTC.
  • Дата и время в строках QUIK — строка ISO 8601 без часового пояса, время UTC+6. У дат (TradeDate, LoadDate, nextcoupon) время нулевое. У времени (time в п. 4.2) значима только часть времени; дата «1900-01-01» — заполнитель QUIK.
  • Время в полях шлюза (expires_at, created_at, last_used_at) — ISO 8601 в UTC.

2.6Повтор заявки

POST /api/v1/orders не идемпотентен. Если ответ получен (201, 202, 422, 502), у заявки есть id и её состояние проверяется по нему. Если ответа нет (таймаут, обрыв соединения), id неизвестен, а в строках Orders нет идентификатора, заданного брокером: заявка ищется в GET /api/v1/orders?date=<сегодня> по совпадению Account, ClientCode, ClassCode, SecCode, Operation, Price и Qty. Повторная отправка — только если совпадения нет.

2.7Отслеживание изменений

Push-уведомлений нет, изменения отслеживаются опросом. Строка Orders появляется в QUIK обычно не позже 0,5 с после отправки заявки.

ДанныеКомментарий
Свои заявкиGET /api/v1/orders/{id} для заявок в ожидании ответа QUIK; GET /api/v1/orders/active — книга заявок фирмы
СделкиПервая страница GET /api/v1/trades?date=<сегодня>; новые строки — с номером TradeNum больше последнего обработанного
ПозицииGET /api/v1/positions/moneylimits и /depolimits, полный снимок
РынокGET /api/v1/market-data, GET /api/v1/quotes

Частота опроса ограничена лимитами п. 8.5.

2.8Трассировка

Заголовок X-Request-ID принимается от клиента или генерируется шлюзом и возвращается в ответе. Указывается в обращениях в поддержку.

5.Заявки

Создание и снятие синхронны: шлюз отвечает после ответа QUIK. Состояние заявок читается из Orders по FirmId токена.

5.1POST /api/v1/orders

Выставление заявки. Имена полей — колонки Orders. Таймаут ожидания ответа QUIK — 10 с.

Список поддерживаемых полей запроса:

ClassCode*строкаКод класса. Значение ClassCode из GET /api/v1/instruments
SecCode*строкаКод инструмента. Значение SecCode из GET /api/v1/instruments
Operation*строкаНаправление. Возможные значения:
  • «Купля»;
  • «Продажа»
PriceчислоЦена, больше 0. С ценой заявка лимитная, без цены — рыночная
Qty*числоКоличество, больше 0
