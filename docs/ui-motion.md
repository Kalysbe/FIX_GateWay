# Анимации операционной консоли

Интерфейс использует рекомендации skill [animate](https://github.com/emilkowalski/skills/tree/main/skills/animate) от Emil Kowalski. Реализация находится в `frontend/src/index.css` и существующих компонентах; дополнительная библиотека не требуется.

| Элемент | Назначение | Переход |
| --- | --- | --- |
| Кнопки | Подтверждение нажатия указателем | Масштаб 0.97, 120 мс |
| Модальные окна | Появление отдельного контекста | Прозрачность и масштаб 0.96 → 1, 240 мс |
| Панель уведомлений | Появление от кнопки вверху справа | Прозрачность и масштаб 0.97 → 1, 180 мс |
| Toast | Появление и исчезновение сообщения | Прозрачность и смещение снизу, 240 мс |
| Мобильная навигация | Сохранение ориентации при открытии панели | Сдвиг сбоку, 240 мс |

Кривые и длительности заданы общими CSS-переменными `--ease-out`, `--ease-drawer`, `--motion-feedback`, `--motion-popover`, `--motion-surface`. Для входа поверхностей используется `@starting-style`; браузеры без его поддержки показывают их сразу. Закрытие модальных окон и панели уведомлений происходит сразу, без задержки действий. Toast удаляется после перехода прозрачности; резервный таймер и очистка эффектов обеспечивают удаление и без события `transitionend`.

Ctrl+K, поиск, смена страниц, строки таблиц и обновления торговых данных не получают анимацию движения. Модальные окна и уведомления, открытые с клавиатуры, появляются сразу. Существующие фокус, Escape и блокировка скрытой мобильной навигации сохраняются.

При `prefers-reduced-motion: reduce` масштабирование, сдвиги и пульсация загрузки отключаются. Для поверхностей остаётся переход прозрачности 120 мс. Hover-эффекты движения не используются; цвет основного действия при наведении меняется только на устройствах с точным указателем и поддержкой hover.

При проверке изменений откройте окно создания брокера, панель уведомлений и мобильное меню, затем повторите с клавиатуры и с системным уменьшением движения. Проверьте быстрые повторные нажатия, фокус после закрытия и несколько последовательных toast-сообщений.
