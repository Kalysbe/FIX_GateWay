# Источник текущих заявок 22.10.2026

- По поручению пользователя текущие заявки читаются из `quik_export2.public."Orders"` PostgreSQL QUIK `192.168.0.89:5432`, через отдельное соединение только для чтения.
- Списки, карточки текущих заявок и `order.updated` используют эту таблицу. Для брокера `FirmId` ограничивается `quik_firm` авторизованного токена, а при пустом значении — кодом брокера. Клиентские параметры не расширяют доступ.
- Строки `Orders` передаются в исходном виде: имена полей, числовые JSON-значения, строки и `null` сохраняются. Не добавлять служебные поля, рассчитанные статусы, объёмы исполнения, историю FIX или трассировку. Список REST — массив строк БД, карточка — одна строка. В gRPC исходный JSON передаётся в `Event.data_json` без преобразования чисел в double; признак удаления находится только в конверте события.
- Локальные `orders`, FIX и outbox сохраняются для приёма/отправки команд, идемпотентности и аудита. Они не являются запасным источником текущего списка. Исчезновение строки из `Orders` не доказывает отмену, истечение срока или исполнение и не переписывает историю.

# Источник текущих торгов 26.10.2026

- По поручению пользователя рыночные данные (`GET /api/v1/market-data`, admin-вариант, gRPC/SSE `marketdata.tick`, страница «Текущие торги») читаются из таблицы QUIK `public."Params"` того же подключения `QUIK_EXPORT_DATABASE_URL` только для чтения. БД QUIK для разработки — `192.168.0.89`, на проде — `172.23.10.84`.
- Строки `Params` передаются в исходном виде (`row_to_json`), как `Orders`: без переименованных или рассчитанных полей; добавляются только названия из `Securities`/`Classes` (см. ниже). Ключ строки — `ClassCode` + `SecCode`; фильтра по фирме нет. В gRPC строка — в `Event.data_json`, удаление — в конверте события.
- По поручению пользователя 26.10.2026 `Params` читается только за текущий торговый день: `TradeDate` = сегодняшняя дата по Бишкеку (UTC+6), во всех потребителях (REST, админка, gRPC). В таблице хранится история по датам. На странице «Текущие торги» `TradeDate` показывается как `dd/mm/yyyy`; JSON API значение не меняет.
- По поручению пользователя 26.10.2026 к строке `Params` в конце добавляются `FaceUnit`, `SecShortName`, `SecFullName` из `public."Securities"` и `ClassName` из `public."Classes"` того же подключения. `Securities` сопоставляется по `ClassCode` + `SecCode` (один `SecCode` бывает в нескольких классах с разными названиями), `Classes` — по `ClassCode`; оба справочника хранятся по `TradeDate`, берётся последняя запись. Нет записи — `null`. Других полей не добавлять.
- FIX Market Data продолжает работать в фоне и питает стакан `/api/v1/orderbook`, но не является запасным источником текущих торгов.

# Счета и фирмы 26.10.2026

- По поручению пользователя торговые счета и фирмы берутся из таблиц QUIK `public."Trdaccs"` и `public."Firms"` (то же подключение только для чтения). Ручное заведение счетов в Gateway убрано; `broker_accounts` не используется для проверки заявок.
- `account_id` заявки допустим, только если в `Trdaccs` есть строка с этим `TrdAccId` и `FirmId` = `quik_firm` токена. `quik_firm` токена выбирается только из `Firms`. Строки отдаются в исходном виде. Подробности — `docs/accounts.md`.
